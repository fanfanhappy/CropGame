# 素材分类目录

原始素材包保留在 `assets/Sprout Lands - Sprites - premium pack/`，运行时和场景引用使用下列规范目录。

```text
assets/
├─ sprites/characters/  角色与动作
├─ sprites/animals/     动物
├─ sprites/crops/       作物
├─ sprites/props/       树木、建筑、环境物件
├─ sprites/tools/       工具
├─ tilesets/            草地、水面、耕地等图集
├─ ui/                  界面、图标、按钮
├─ effects/             水花、粒子、特效
├─ audio/               音效和音乐
└─ fonts/               像素字体
```

归档副本统一使用小写 `snake_case` 文件名；原始包不参与主场景引用，便于替换和回溯。
