# 小溪农场

一个电脑端 2D 像素风种田游戏原型，使用 Godot 4 制作。

## 运行

1. 安装 Godot 4.7 或更新版本。
2. 在 Godot 项目管理器中导入本目录。
3. 点击运行项目。

## 操作

- `WASD` / 方向键：移动
- 鼠标左键：指向地块后翻地、播种或收获
- 鼠标右键：指向任意耕地或作物浇水
- `T`：进入下一天，让已浇水的作物生长

当前原型包含农场地图、小溪、房屋、树木、作物生长阶段、金币和种子数量。

草地和水面都已准备为 `TileMapLayer` 图层；`tileset_water.png` 的 4 帧会自动循环播放水面波动。
